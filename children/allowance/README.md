# 신씨네가족 용돈규칙

`index.html`을 브라우저에서 열면 됩니다. 화면과 실행 코드를 한 파일에 넣어 두었습니다. 인터넷 연결이나 설치 없이 이 컴퓨터에서 사용할 수 있습니다.

## 처음 사용할 때

1. 맨 위 **용돈규칙**과 아이별 금액을 확인합니다. 완은 중2, 윤은 초6, 하는 초5(2026년 기준)로 설정했습니다.
2. 시작값은 2026년 9월 26일 기준으로 알려주신 금액에 맞췄습니다. 주완은 총 보상 2,939,200원·총 사용 3,022,100원·잔액 -82,900원, 윤아는 2,589,200원·1,612,500원·976,700원, 주하는 1,965,900원·1,948,000원·17,900원입니다. **시트 시작값**에서 나중에 직접 수정할 수 있습니다.
3. 말해보카는 월요일부터 일요일까지의 성공 횟수를 완·윤·하 순서로 입력합니다. 9월 14~20일 실적의 보상일은 9월 20일입니다. 7회면 5,000원입니다.
4. 슈퍼워크는 실적 월을 선택한 뒤 세 아이의 워크 수를 입력합니다. 8월 실적의 기본 보상일은 9월 1일입니다. 300워크면 수리비 20%를 제외해 24,000원입니다.
5. 현질 등 사용 금액은 **사용·현질** 탭에서 항목과 실제 사용일을 골라 기록합니다. **+ 추가 → 항목 저장**으로 항목을 만들고, 목록에서 선택한 뒤 **삭제**할 수 있습니다. 목록에서 삭제해도 이전 사용 기록의 항목명은 유지됩니다. 잔액은 하나로 합산됩니다.
6. 어린이날은 5월 5일, 크리스마스는 12월 31일이 기본 날짜입니다. 생일은 주완 7월 20일, 윤아 2월 12일, 주하 10월 7일로 자동 선택됩니다. 실제 보상일은 바꿀 수 있습니다.

입력 시각은 자동으로 남고, 보상일·사용일은 별도로 저장됩니다. 보상일이 아직 오지 않은 금액은 현재 사용 가능 금액에 더하지 않습니다. 과거 날짜를 몰아서 입력해도 입력한 날짜로 바뀌지 않습니다.

## 수정과 기록

- 같은 말해보카 주 또는 슈퍼워크 월을 다시 저장하면 같은 아이의 기록이 수정됩니다. 중복 보상은 생기지 않습니다.
- **기록 내역** 위의 추가 버튼으로 입력 화면으로 바로 이동할 수 있습니다. 아이·항목·월로 찾고, 기록의 **수정** 또는 **삭제**를 누르세요. 삭제한 기록은 내역에 남고 **수정·복구·완전 삭제**할 수 있습니다. 완전 삭제는 현재 장부에서 기록과 수정 이력을 지우며, 이전에 저장한 JSON 백업은 그대로 남습니다.
- **용돈규칙 수정**에서 기본 용돈, 보상 단가, 보너스, 수리비 비율, 특별 용돈을 바꿀 수 있습니다. 이미 저장한 정산액은 유지되며 새로 입력하는 기간에는 적용 시작일의 규칙이 쓰입니다.
- 시트 시작값에 이미 들어 있는 과거 기록은 **시트에 이미 포함**으로 표시하면 잔액에 중복 반영되지 않습니다. 시트 합계를 새로 입력할 때 모든 과거 기록이 그 합계에 포함된 것은 아니라면 일괄 포함을 선택하지 말고 기록마다 수정하세요.
- 기존 버전의 일~토 말해보카 기록은 날짜와 금액을 그대로 보존합니다. 새 월~일 기간과 겹칠 경우 중복 기록 여부를 확인하는 안내가 나옵니다.
- 이전 버전에서 저장한 기록은 유지하면서 시작 누계를 조정해 위의 2026년 9월 26일 총 보상·잔액에 맞춥니다. 이후 새 기록은 날짜에 따라 잔액에 반영됩니다.

## 기존 장부와 백업

이 파일의 장부는 **열어 사용한 브라우저의 로컬 저장소**에 보관됩니다. 파일을 E:로 옮겨도 이전 파일에서 입력한 내용이 자동으로 따라오지는 않을 수 있습니다.

- 이전 `family-allowance.html`에 실제 기록이 있다면, 이전 파일을 사용하던 **같은 브라우저**에서 열어 **백업 저장**을 누릅니다.
- 새 `index.html`에서 **백업 불러오기**로 그 JSON 파일을 선택합니다. 이전 버전의 JSON도 자동으로 새 구조로 변환합니다.
- 기록을 입력하거나 수정한 뒤에는 **백업 저장**을 눌러 JSON 사본을 다른 폴더에도 보관하세요. CSV는 스프레드시트로 확인하는 용도이며, 복구에는 JSON이 필요합니다.
- 다른 컴퓨터나 휴대폰에서는 이 장부가 자동으로 보이지 않습니다. PC를 끄고 휴대폰에서도 사용하려면 별도의 온라인 저장 기능이 필요합니다.

## 파일

`index.html`이 실행 파일입니다. `app.js`는 유지보수용 원본입니다. `tests` 폴더에는 계산과 데이터 검사 스크립트가 있습니다. 개발 점검 시 Node.js에서 `node tests/ledger.test.mjs`와 `node tests/structure.test.mjs`를 실행할 수 있습니다.
